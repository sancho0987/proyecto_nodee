# 📌 Task Manager API (Node.js + Express + PostgreSQL)

API REST para gestión de usuarios y tareas, con autenticación basada en JWT, protección con rate-limit, CORS seguro y Passport para validar tokens.

---

## 🚀 Características principales

- Registro e inicio de sesión con contraseñas encriptadas (bcrypt).
- Autenticación mediante JWT (Passport Strategy).
- CRUD completo de tareas.
- Rate Limit para proteger las rutas de autenticación.
- CORS restringido al frontend.
- Estructura modular (routes/controllers/middlewares).
- Variables de entorno separadas y seguras.
